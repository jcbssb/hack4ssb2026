Haskell DSL Type Hierarchy
data Dialogue
Top-level container containing survey identity, contextual metadata, and ordered dialogue steps.
data Question
Atomic dialog step binding a prompt, question type, required predicate, and target annotations.
data QuestionType
• QText (string input)
• QTextArea (multiline text)
• QInteger (integer number)
• QDecimal (decimal number)
• QDate (date picker)
• QBoolean (yes/no)
• QChoice [String] (single choice)
• QMultiChoice [String] (checkboxes)
data Predicate
• Equals FieldId String
• NotEquals FieldId String
• IsTrue FieldId
• And [Predicate]
• Or [Predicate]
data Prompt
Plain language label and optional guidance text for respondents.

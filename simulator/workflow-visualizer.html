Rolle: AI & Utvikler

Input & Prosess

  • • Input: Tekstkrav, spørreskjema-skisser, XSD-skjemaer eller JSON Schema.
  • • AI-mapping: Datatyper (string, boolean, integer, enum) mappes til standard UI-komponenter.
  • • Figma Plugin: Oppretter frames med Auto Layout, spørsmålstekster og feltkomponenter.

Synergi: Opprinnelig Figma-flyt vs. Dialogue DSL

Hvordan Haskell Dialogue DSL komplementerer og forsterker den opprinnelige Figma-til-Altinn visjonen:

Fase / Dimensjon Opprinnelig Flyt (Figma ➔ Altinn) Foran Skjema (Dialogue DSL SSOT)
Single Source of Truth Figma Design Canvas Typet Haskell DSL AST (dekker regler, validering, layout)
Iterasjonsarena Figma UI Editor (visuelt) Toveis: Figma for UX + Nettleser-simulator for logikk
Altinn 3 Ekstraksjon Figma REST API / Plugin parser Deterministisk kompilator (SchemaDSL.Altinn.Compile)
Modellkonsistens Manuell/semi-auto C# & JSON Schema sync 100% automatisk injeksjon av C#, XSD, Layout og Tekster

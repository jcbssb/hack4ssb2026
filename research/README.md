# Research Guide & Findings Directory

This directory stores synthesized research outputs produced by or for research agents.

## Output Format Standard for Research Findings

When writing a research finding note (e.g. `research/<topic>.md`), follow this structure:

```markdown
# [Topic Title]

**Status**: Verified / In-Progress  
**Updated**: YYYY-MM-DD  
**Relevant Repos/Sources**: [paths or URLs]

## TL;DR
[1-2 sentences summarizing the core finding]

## High-Density Specs & Findings
- **Endpoint/Schema**: `...`
- **Key Parameters / Types**: `...`
- **Caveats / Constraints**: `...`

## Exact Source Pointers
- `/path/to/file.ext:line` - [Brief description]
- `https://docs.altinn.studio/...` - [Docs reference]

## Actionable Next Step for Implementation Agent
- [Step 1]
- [Step 2]
```
